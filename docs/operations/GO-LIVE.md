# Go-live: what only the owner can do

Everything that can be built, tested and wired in the repository is done; what is left needs an account, a secret, a domain or a legal decision that no code change can supply.
This page is the ordered index. Each step names the document with the detail. A step is not "done" because the code for it exists: the last column says what proves it.

Status words: **blocked** (cannot start without the owner), **ready** (everything is wired, the owner only supplies the value).
